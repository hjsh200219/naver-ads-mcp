## 12 원칙 (간단)

1. 리포지터리 = 기록 시스템
2. 진입 문서는 map, not handbook
3. 아키텍처 기계적 강제
4. Search Before Building
5. 작업은 상태로 끝난다 (DONE/DONE_WITH_CONCERNS/BLOCKED/NEEDS_CONTEXT)
6. 회의적 평가 (자기평가 편향 상쇄)
7. 하네스 단순화 (모델 능력 가정 재검증)
8. Phase 독립 에이전트 (context reset > compaction)
9. Sprint Contract (수정 전 기대 효과 합의)
10. 채점 앵커 (점수대별 구체 예시)
11. TDD 게이트 (새 기능 실패 테스트 먼저)
12. 보안 게이트 (자격증명·secret 누출 방지)
