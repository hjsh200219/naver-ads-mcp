## Patterns / Learnings
- `.env` parsing: trailing space in key name (`KEY = value` vs `KEY=value`) breaks dotenv; loader must trim and tolerate both
- HMAC payload format: `{epoch_ms}.{method}.{path}` (path only, NO query string)
- Headers: X-Timestamp, X-API-KEY (=ACCESS_LICENSE), X-Customer (=CUSTOMER_ID), X-Signature (=base64 HMAC)
- StatReport flow: POST → poll GET → BUILT → downloadUrl → GZ → TSV
- Conversion breakdown: AD_CONVERSION reportTp's convTpCd field maps to 4 columns (구매완료/회원가입/신청완료/기타전환)
- Data retention: AD_CONVERSION_DETAIL = 45 days only (daily collection cron required for production)
- 월별/주차 columns are derived from 날짜 client-side, not from API
